# 반려식물 케어 서비스

## 사용자와 목표
- 사용자: 식물을 자주 시들게 만드는 초보 식집사
- 목적: 반려식물의 케어 조건과 집 안의 일조량·환기 환경을 등록해 식물을 건강하게 관리하기

## 사용자의 흐름
1. 정보 활용에 동의하고 '맞춤형 케어 시작하기'를 누른다.
2. 반려 식물의 이름을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 반려 식물을 돌볼 수 있는 시간을 선택하고 필요하면 키우기 시작한 일 수를 포함한다.
4. 이름, 시간, 키우기 시작한 일 수를 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터렉션 시나리오
1. 시작과 정보 활용 안내
- 행동, 이벤트 : 기존 동의 체크박스를 선택하고 '맞춤형 케어 시작하기'를 클릭한다.
- 조건 : 정보 활용 동의가 선택되었는가?
- 반응, 다음 상태 : 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다.
                  팝업에서 '돌아가기'를 누른거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
                  '동의하고 설정 시작하기'를 누르면 이름 입력 화면을 연다.
2. 이름 입력
- 행동, 이벤트 : 반려 식물의 이름을 적고 '케어 조건 선택하기'를 클릭한다.
- 조건 : 앞뒤 공백을 지운 이름이 비어 있는가?
- 반응, 다음 상태 : 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                  값이 있으면 저장하고 조건 선택으로 이동한다.
3. 조건 선택
- 행동, 이벤트 : 돌볼 수 있는 시간을 바꾸거나 키우기 시작한 일 수를 선택하고 '내용 확인하기'를 클릭한다.
- 조건 : 키우기 시작한 일 수를 선택했는가?
- 반응, 다음 상태 : 선택했을 때만 키우기 시작한 일 수를 보여준다.
4. 내용 확인
- 행동, 이벤트 : 이름, 시간, 키우기 시작한 일 수 내용을 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건 : 수정인가, 완료인가?
- 반응, 다음 상태 : 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
                  완료하면 완료 안내로 이동한다.
5. 완료와 다시 설정
- 행동, 이벤트 : 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태 : 새 설정의 이름, 시간, 키우기 시작한 일 수, 진행 상태를 초기화하고 이름 입력부터 다시 시작한다.
                  이미 확인한 정보 활용 동의와 다른 기능을 유지한다.

## 중간고사에서 새로 추가한 기능
맞춤형 케어 설정을 반려 식물 설정으로 바꾸기 및 서비스에 맞게 이름을 바꾸고 '환경 등록하기' 버튼을 추가하여 일조량·환기 환경을 등록할 수 있도록 경로를 추가했습니다. 사용자는 식물 종류와 창문 방향, 계절, 창문 주변 조건, 환기 상태를 입력 및 선택하고 확인한 뒤 환경 등록을 완료하거나 다시 설정할 수 있습니다.

## 새 기능 사용자의 흐름
1. 반려 식물 설정 완료 화면에서 '환경 등록하기'를 누른다.
2. 식물 종류를 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 식물 종류, 창문 방향, 계절, 창문 주변 환경과 환기 상태를 선택한다.
4. 입력 내용을 확인하고, 필요하면 다시 설정하거나 완료한다.

## 새 기능 인터랙션 시나리오
1. 환경 등록 시작
- 행동, 이벤트 : 반려 식물 설정완료 화면에서 '환경 등록하기'를 누른다.
- 조건 : 환경 등록 버튼을 눌렀는가?
- 반응, 다음 상태 : 반려 식물 설정 화면이 숨겨지고 식물 종류 입력 화면을 연다.

2. 식물 종류 입력
- 행동, 이벤트 : 식물 종류를 입력하고 '창문 방향 등록하기'를 누른다.
- 조건 : 앞뒤 공백을 제외한 입력값이 비어 있는가?
- 반응, 다음 상태 : 비어 있으면 식물 종류 입력 안내를 표시하고 입력창에 초점을 둔다.
                  값이 있으면 저장하고 창문 방향 선택으로 이동한다.
                  '반려 식물 설정으로 돌아가기'를 누르면 환경 등록 화면을 닫고 맞춤형 케어 완료 화면으로 돌아간다.

3. 창문 방향과 계절 선택
- 행동, 이벤트 : 창문 방향 하나와 계절 하나를 선택하고 '주변 환경 등록하기'를 누른다.
- 조건 : 창문 방향과 계절을 각각 선택했는가?
- 반응, 다음 상태 : 둘 중 하나라도 선택하지 않으면 안내 문구를 보여주고 현재 화면에 머문다.
                  모두 선택하면 선택값을 저장하고 주변 환경 선택 화면으로 이동한다.

4. 주변 환경 선택
- 행동, 이벤트 : 유리창 종류, 커튼·차양, 방충망, 창문 밖 가림, 창문에서 식물까지의 거리, 환기 상태를 선택하고 '내용 확인하기'를 누른다.
- 조건 : 각 항목에서 선택했는가?
- 반응, 다음 상태 : 선택이 빠진 항목이 있으면 안내 문구를 표시하고 현재 화면에 머문다.
                  모두 선택하면 선택값을 저장하고 입력한 내용 확인 화면으로 이동한다.

5. 내용 확인
- 행동, 이벤트 : 입력한 식물, 환경 정보를 확인하고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건 : 수정인가, 완료인가?
- 반응, 다음 상태 : 수정하면 기본 값을 유지하고 주변 환경 선택으로 돌아간다.
                  완료하면 완료 안내로 이동한다.

6. 완료와 다시 등록
- 행동, 이벤트 : 완료 안내를 읽고 필요하면 '환경 다시 등록하기'를 클릭한다.
- 반응, 다음 상태 : 입력한 식물 종류, 창문 방향과 계절 / 유리창 종류 / 커튼·차양 / 방충망 / 창문 밖 가림 / 창문에서 식물까지의 거리 / 환기 상태의 선택값, 진행 상태를 초기화하고 식물 종류 입력부터 다시 시작한다.
                  '완료 화면 닫기'를 누르면 환경 등록 화면을 닫고 이미 확인한 정보 활용 동의와 다른 기능은 유지한다.

## 9주차 추가·수정 기능
반려 식물 설정에 입력한 이름의 글자 수가 1자일 때 2자 이상 입력 안내를 표시하도록 수정했습니다. 반려 식물 설정과 일조량·환기 환경 등록의 설정 완료 버튼을 누르면 저장 중 상태를 표시하고 600ms 뒤 완료 화면으로 이동합니다. 저장한 반려 식물 목록에서 저장 날짜와 케어 정보를 확인할 수 있으며, 상세 화면에는 등록한 일조량·환기 환경도 표시됩니다.

## 입력 조건
- 반려 식물 이름은 공백을 제외하고 2자 이상 입력합니다. 입력 칸은 최대 60자입니다.
- 환경 등록에서는 창문 방향과 계절을 선택하고, 주변 환경의 각 항목도 하나씩 선택합니다.

## 확인 순서
1. 반려 식물 이름을 비우고 다음 단계로 이동해 오류 안내를 확인합니다.
2. 한 글자와 두 글자 이상을 입력하며 오류 안내, 입력 조건 안내, 글자 수가 갱신되는지 확인합니다.
3. 키우기 시작한 일 수를 선택하고 해제해 질문 수 영역이 열리고 닫히는지 확인합니다.
4. 케어 정보를 확인하고 설정 완료를 눌러 저장 중 표시와 완료 화면을 확인합니다.
5. 저장한 반려 식물 목록에서 날짜와 케어 정보를 확인하고, 상세 화면을 엽니다.
6. 환경 정보를 등록한 뒤 상세 화면에서 등록한 정보가 표시되는지 확인합니다.
7. 각 다시 설정 기능을 눌러 입력값과 안내 문구가 초기화되는지 확인합니다.

## 저장 실패 처리
- 케어 정보를 저장하지 못하면 오류 안내를 표시하고 완료 화면으로 이동하지 않습니다. 관련 코드는 script.js 파일에서 saveCareSettings()와 careForm의 submit 처리 부분에 있습니다.
- 저장된 반려 식물 정보를 찾을 수 없거나 환경 정보 저장에 실패하면 완료 화면으로 이동하지 않고 오류 안내를 표시합니다. 관련 코드는 script.js 파일에서 environmentFinishButton 클릭 처리 부분에 있습니다.

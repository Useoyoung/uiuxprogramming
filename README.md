# 2주차 HTML 수정 기록
수업 중 작성한 사용자·목적·핵심 행동·정보 순서 주석을 자기 서비스에 맞게 보완하고, 구현하면서 바꾼 구조와 변경 이유
1. 수업 중 작성한 주석의 정보 순서 마지막 항목을 페이지 하단의 이메일 수신 폼의 역할과 기획 주석을 완벽하게 일치시키기 위해 기존의 세션 설정에서 소식 받기로 수정했습니다.
2. 한눈에 정보를 파악하게 하기 위해 서비스 소개 부분의 p태그 부분을 1개(1줄)로 수정했습니다.
3. 이미지의 사이즈가 커서 HTML코드 내에 img코드에 style코드를 추가하여 보기 편하게 수정했습니다.

# 3주차 CSS 수정 기록
## 수정한 내용
메뉴가 깔끔하고 조금 더 눈에 띌 수 있도록 'nav a'에 'padding'과 'border' 값을 주고 'text-decoration-line: none'을 적용하여 링크로 인해 생성된 밑줄을 없앴습니다.
그리고 'hover'와 'focus'를 추가함으로써 어떤 메뉴를 선택하는지 조금 더 명확하게 알 수 있도록 적용했습니다.
## 수정한 이유
사용자가 메뉴 버튼을 조금 더 인식할 수 있고, 어떤 메뉴를 선택하는지 조금 더 명확하게 인지하도록 수정했습니다.

# 반려식물 케어 서비스

## 사용자와 목표
- 사용자: 식물을 자주 시들게 만드는 초보 식집사
- 목적: 맞춤형 케어 일정 알림과 상태 진단으로 반려식물을 건강하게 키우기

## 사용자의 흐름
1. 정보 활용에 동의하고 '맞춤형 케어 시작하기'를 누른다.
2. 반려 식물의 이름을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 반려 식물을 돌볼 수 있는 시간을 선택하고 필요하면 질의 응답을 포함한다.
4. 이름, 시간, 질의응답 설정을 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터렉션 시나리오
1. 시작과 정보 활용 안내
- 행동, 이벤트 : 기존 동의 체크박스를 선택하고 '맞춤형 케어 시작하기'를 클릭한다.
- 조건 : 정보 활용 동의가 선택되었는가?
- 반응, 다음 상태 : 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다.
                  팝업에서 '돌아가기'를 누른거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
                  '동의하고 설정 시작하기'를 누르면 제목 입력 화면을 연다.
2. 이름 입력
- 행동, 이벤트 : 반려 식물의 이름을 적고 '케어 조건 선택하기'를 클릭한다.
- 조건 : 앞뒤 공백을 지운 이름이 비어 있는가?
- 반응, 다음 상태 : 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                  값이 있으면 저장하고 조건 선택으로 이동한다.
3. 조건 선택
- 행동, 이벤트 : 돌볼 수 있는 시간을 바꾸거나 질의 응답을 선택하고 '내용 확인하기'를 클릭한다.
- 조건 : 질의응답을 선택했는가?
- 반응, 다음 상태 : 선택했을 때만 질문 수를 보여준다.
4. 내용 확인
- 행동, 이벤트 : 이름, 시간, 질의응답 내용을 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건 : 수정인가, 완료인가?
- 반응, 다음 상태 : 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
                  완료하면 완료 안내로 이동한다.
5. 완료와 다시 설정
- 행동, 이벤트 : 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태 : 새 설정의 이름, 시간, 질의응답, 진행 상태를 초기화하고 이름 입력부터 다시 시작한다.
                  이미 확인한 정보 활용 동의와 다른 기능을 유지한다.
